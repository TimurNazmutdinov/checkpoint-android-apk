# Чекпоинт — APK для тестирования

Это **прототип** приложения «Чекпоинт» (трекер целей и задач) — только для тестирования. Код приложения здесь не хранится, только готовые файлы установки (APK) в разделе [Releases](../../releases).

## Как установить
1. Откройте [последний релиз](../../releases/latest) на телефоне и скачайте файл `Checkpoint-….apk`.
2. Откройте скачанный файл. Если телефон спросит, **разрешите установку из этого источника** (один раз).
3. Нажмите «Установить».

## Как обновить
Приложение само проверит новую версию при запуске. Если вышла новая, оно предложит скачать её. Скачайте APK и **установите поверх** старой: цели и задачи сохранятся. Удалять приложение не нужно.

## Файл `latest.json`
Приложение читает из него номер последней версии и заметки. Ничего о вас на сервер не отправляется.
